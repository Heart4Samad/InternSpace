# 🚀 InternSpace Workspace Portal

InternSpace is a high-performance web application designed to help corporate interns manage their onboarding checklists and sprint tasks. Built with a premium neon black and electric gold user interface, it provides a highly interactive workspace experience.

## ✨ Core Features

*   **Interactive Splash Screen:** Features a draggable light switch animation with live sound design to power on the application dashboard.
*   **Audio Engine Layer:** Context-aware background music and mechanical sound effects synced safely to direct user interactions.
*   **Dual Offline & Online Operation:** Configured as a fully functional Progressive Web App (PWA) that loads instantly without a Wi-Fi connection.
*   **Local Storage Sync:** Stores accounts, onboarding status updates, and Agile Kanban boards directly inside the browser sandbox.

## 🛠️ Built With

*   **HTML5** - Page layout structure
*   **CSS3** - Premium neon design system and animations
*   **Vanilla JavaScript** - Core system logic, audio controls, and drag physics
*   **Service Worker API** - Offline asset caching engine
*   **AI Collaboration** - Refined background script architectures

## 📱 Mobile Installation

This platform is fully responsive and optimized for mobile devices. To install it on your smartphone:
1. Open your live Netlify web link in your phone's browser.
2. Tap the **Install App** alert widget or select **Add to Home Screen** from your browser options menu.
